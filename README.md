# noise-overlay

Un mascot overlay transparent qui affiche le niveau sonore de la classe en temps réel, pour aider à garder le calme.

## Développement

```
npm start
```

## Générer l'exécutable Windows

```
npm run dist
```

Produit un `.exe` portable dans `release/` — pas d'installeur, pas besoin de droits admin. Il suffit de le copier et de le lancer.

Windows demandera l'autorisation d'accès au microphone au premier lancement.

## Raccourcis clavier globaux

| Raccourci        | Action                  |
|-------------------|--------------------------|
| Ctrl+Shift+P      | Panneau de réglages      |
| Ctrl+Shift+F      | Plein écran              |
| Ctrl+Shift+Q      | Quitter                  |

Une icône est disponible dans la barre système.
